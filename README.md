## Login com Google (opcional)

O site funciona sem login e guarda as respostas no browser. Para guardar na tua conta:

1. Cria um projeto em https://console.firebase.google.com.
2. Em **Authentication → Sign-in method**, ativa o **Google**. Em **Settings → Authorized domains**, junta `joanactc.github.io`.
3. Em **Firestore Database**, cria a base de dados e, em **Rules**, cola o conteúdo de `firestore.rules` e publica.
4. Em **Project settings → Your apps**, cria uma app **Web** e copia `apiKey`, `authDomain`, `projectId` e `appId` para `firebase-config.js`.
